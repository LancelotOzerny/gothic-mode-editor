# Правила разработки

- Выполняй только поставленную задачу, вноси минимальные необходимые изменения.
- Используй существующие классы, структуру `core/` и `ui/`, схемы и компонентную модель.
  Соблюдай SOLID без лишних абстракций. Сторонние библиотеки — только с разрешения.
- Сохраняй пользовательские изменения, неизвестные поля, выражения Daedalus,
  связанные функции и соседние INSTANCE импортированных предметов.
- Оригиналы Gothic и файлы других модов не изменяй. Сборка использует временные копии;
  установка меняет только разрешённые файлы мода и предусмотренный резервируемый кэш.
- Учитывай кодировку, регистр идентификаторов, пути с пробелами и совместимость
  с компилятором/GothicStarter. Не меняй сборку, установку и запуск без необходимости.
- `codex/ROADMAP.md` пользователь редактирует параллельно: не перезаписывай его
  изменения, обновляй только статус выполненной задачи согласно PIPELINE.
