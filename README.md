# Gothic Editor 0.2 (Python / Tkinter)

Требуется **Python 3.10+**. Сторонние пакеты не требуются.

## Запуск

```bash
python main.py
```

## Порядок работы

1. «Файл → Создать проект»: выберите **отдельную** папку мода, например `D:/projects/MonasteryExpansion`. В ней появятся `project.json` и `Scripts/Content/Items/`.
2. (Необязательно) Откройте «Проект → Настройки», выберите слева «Ресурсы» и задайте путь к корню установленной Gothic II, содержащему `_work/data/Scripts/Content`, **либо** к корню распакованных исходных `.d`-файлов. Нажмите «Сохранить». Пустой путь отключает игровые ресурсы. Если скриптов нет, установите Gothic 2 MDK / распакуйте исходники.
3. Категории слева раскрываются нажатием, кнопка `+` создаёт новый предмет в проекте. Для проектных предметов доступны «Дублировать» и «Удалить»; для игровых — «Дублировать в проект». Двойной щелчок изменяет `name` (название в игре).
4. Справа можно редактировать выражения Daedalus; кнопка «Сохранить в проект» записывает изменения **только в папку проекта**.
5. Для 3D-просмотра `.3DS` положите распакованные модели в `Assets/Models`. Если внешний `.3DS` не найден, редактор ищет модель в VDF подключённой Gothic II: например, для `ItPo_Health_01.3ds` — `ITPO_HEALTH_01.MRM`. ЛКМ вращает, колёсико масштабирует.

## Просмотр моделей из VDF

- В «Проект → Настройки → Ресурсы» укажите корень Gothic II, содержащий `Data/*.vdf`.
  Для автоматического поиска скриптов предметов также нужны распакованные `.d`
  в `_work/data/Scripts/Content`, как и раньше.
- Внешний `.3DS` имеет приоритет. При его отсутствии проверяются `.3DS` и
  скомпилированный `.MRM` внутри архивов. Поиск по имени не учитывает регистр.
- Дополнительные архивы проекта можно положить непосредственно в `Data/` или
  `Assets/` проекта. Они имеют приоритет перед игровыми архивами; среди архивов
  одной группы выбирается модель из архива с более новой внутренней датой.
  Неактивные моды в `Data/ModVDF` автоматически не подключаются.
- Архивы целиком не распаковываются. Каталоги индексируются при обновлении ресурсов,
  выбранная модель читается в фоне, последние восемь моделей кешируются.
  После добавления или изменения архивов нажмите «Файл → Обновить данные».
- Поддерживается геометрия статических `.MRM` Gothic I/II и `.3DS` в стандартных
  несжатых VDF (`0x50`). Текстуры, анимационные модели и сжатые VDF (`0xA0`) пока
  не поддерживаются. Повреждённые архивы отражаются в списке `repo.errors` и счётчике
  ошибок строки состояния; ошибки чтения выбранной модели выводятся в просмотрщике.
- Описание [VDF](https://zk.gothickit.dev/engine/formats/vdf/) и структура
  [MRM в ZenKit](https://github.com/GothicKit/ZenKit/blob/main/src/MultiResolutionMesh.cc)
  использованы как справочник форматов. Зависимости на ZenKit нет.

## Настройки и локализация

«Проект → Настройки» открывает окно с разделами слева и настройками справа.
В «Интерфейсе» можно выбрать язык и начальный размер окна, в «Ресурсах» — подключить
или отключить Gothic II для открытого проекта. Изменения применяются кнопкой
«Сохранить»; «Отмена» оставляет прежние значения.

- `assets/settings.json` описывает разделы (`sections`), группы и поля (`settings`).
  Формат основан на Pixel Matrix Studio. Поддерживаются `boolean`, `string`,
  `number`, `size`, `color`, а также `directory` и `language`.
- Поле содержит `code`, ключи перевода `name` и `title`, `type` и `default`.
  Для чисел доступны `minimum` и `maximum`. Новые поля общих настроек автоматически
  отображаются и сохраняются; применение их значения к поведению редактора
  нужно реализовать отдельно.
- `assets/lang/ru.json` содержит русские тексты интерфейса. Чтобы добавить язык,
  скопируйте файл в `<код>.json`, задайте `language.code`, совпадающий с именем файла,
  и `language.name` — название языка в списке. Переведите текстовые значения,
  сохранив ключи и подстановки вроде `{total}`. Новый язык появится при следующем
  открытии настроек. Отсутствующие переводы берутся из `ru.json`.
- Пользовательские значения сохраняются отдельно: в Windows —
  `%APPDATA%/GothicEditor/settings.json`, в остальных системах —
  `~/.config/GothicEditor/settings.json`. Каталог в `assets` остаётся описанием формы.
- Путь к Gothic II имеет область `project` и хранится в `project.json` выбранного
  проекта, сохраняя совместимость с существующими проектами. Без открытого проекта
  это поле недоступно. Чтобы отключить игровые ресурсы, очистите путь и сохраните.

Проверки запускаются стандартной библиотекой: `python -m unittest discover -s tests -v`.
Для проверок интерфейса нужен работающий Tkinter и доступ к графическому окружению.

## Ограничения прототипа

- Редактор работает с непосредственными `INSTANCE (...) (C_Item)` и прямыми присваиваниями. Если предмет получает параметры через прототип, функции, условную логику или константы, вычисления не выполняются. Категории в таких случаях могут быть неточными; нераспознанные предметы — в «Разное».
- У скриптов Gothic нередко кодировка Windows-1251. Редактор сохраняет кодировку при изменениях существующих файлов и использует Windows-1251 для новых предметов; неподдерживаемые символы вызывают ошибку сохранения вместо порчи файла.
- Редактор **не компилирует мод**, не меняет `Gothic.src`, не устанавливает мод в игру и не разрешает конфликты определений между оригиналом и проектом. При сборке потребуется корректно заменить оригинальные скрипты проектными, а не подключать оба файла с одинаковыми `INSTANCE`.
- Удаление из проектной копии оригинального многопредметного файла удаляет его определение **только из проектной копии**, но это не эквивалентно удалению из игры до правильной сборки мода. Не импортируйте все проектные `.d` рядом с оригинальными без учёта дублей.
- Изменение поля на существующем игровом предмете копирует **весь содержащий его исходный `.d`-файл** в проект при сохранении (Copy-on-Write). Оригинал остаётся нетронутым.
- Пустые или невалидные выражения Daedalus могут не скомпилироваться. Значения вводятся как код (например, `"Зелье"`, `100`, `ITEM_KAT_POTIONS`).
- Подробная классификация некоторых разновидностей украшений, свитков и оружия эвристическая; на разных модификациях она может отличаться.
