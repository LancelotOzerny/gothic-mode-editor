# Длинные книги и записки в обычной Gothic

Тексты в `Assets/Texts/` автоматически разбиваются на страницы с сохранением
заголовков и абзацев. Жёсткого ограничения в две страницы на весь файл больше нет.

Обычный интерфейс документов Gothic не поддерживает перелистывание более чем
одного двухстраничного разворота в одном окне. Поэтому генератор создаёт для
каждого разворота отдельное окно `Doc_Create/Doc_Show`. Читатель:

1. Открывает книгу и видит первые одну-две страницы.
2. Закрывает её и **открывает предмет снова**, чтобы увидеть следующие страницы.
3. После последнего разворота следующее открытие начинается с начала.

Для книг используются текстуры `Book_Mage_L.tga` / `Book_Mage_R.tga`,
для записок — `letters.TGA`. Каждый вызов `Doc_SetPages` задаёт не более двух
страниц, что совместимо с обычным интерфейсом Gothic.

Функция действия книги, в том числе «Изучить рецепт», вызывается на первом
развороте. На промежуточных разворотах действие не повторяется.

**Ограничение:** это переход между разворотами через повторное использование
предмета, а не кнопки перелистывания внутри открытой книги. Для настоящего
листания в одном окне требуется расширение движка, например GEngine.
Изображение всех разворотов в реальной игре необходимо проверить отдельно.
