# Изучение алхимических рецептов через действие

В редакторе действий книг, записок и других предметов доступна группа
**Алхимия → Изучить рецепт (GE_LearnRecipe)**. У параметра **Рецепт**
отображается список существующих рецептов с доступностью
`global_variable`. Вручную вводить имя переменной или число не нужно.

Действие можно назначить нескольким предметам: одна книга изучит несколько
рецептов, если добавить несколько действий «Изучить рецепт».

При сборке редактор создаёт только в staging файле
`GE_Recipes/Learning.d`:

```c
const int GE_LEARN_ID_HEALTH = 123456; // Код зависит от ID, здесь пример
var int GE_KnowsHealth;

func void GE_LearnRecipe(var int recipe)
{
    if (recipe == GE_LEARN_ID_HEALTH) { GE_KnowsHealth = TRUE; };
};
```

Имена констант `GE_LEARN_ID_<ID>` можно использовать в Daedalus вручную:
`GE_LearnRecipe(GE_LEARN_ID_HEALTH);`.

Функция меняет только уже существующую переменную знания, которую проверяет
алхимический стол. Повторное изучение безопасно. Если один флаг знания
привязан к нескольким рецептам, они разблокируются вместе.

При отсутствии изучаемых рецептов действие не показывается. Никакие изменения
исходных скриптов Gothic и данных проекта при сборке не выполняются.

Учитель сможет вызвать ту же функцию после проверки золота, LP или других
условий. Торговля и размещение предметов в ZEN не входят в эту задачу.
