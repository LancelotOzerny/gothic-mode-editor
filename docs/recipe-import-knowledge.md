# Знание рецептов при импорте из Gothic

**Новый рецепт** использует существующие настройки доступности редактора.
Новую переменную знания автоматически не создаём.

**Импортированный стандартный рецепт** переносит ингредиенты, количества,
результат, название, категорию и оригинальный признак изучения алхимии
`PLAYER_TALENT_ALCHEMY[POTION_...]`, если он однозначно распознаётся
в `Potion_Alchemy.d`. Сохраняется тип доступности `stock_talent`
и конкретный индекс `talent`.

Например, после обучения у штатного NPC меняется соответствующий элемент
`PLAYER_TALENT_ALCHEMY`, поэтому дополнительная переменная не нужна.

Если оригинальное условие изучения не распознано однозначно, импортёр
пропускает рецепт и учитывает его среди нераспознанных. Он **не**
подставляет `always` вместо неизвестной проверки.

Для **уже импортированных** рецептов выполните ПКМ по исходной
категории → «Импорт всех рецептов». У записей с исходным `COPY_...`
идентификатором и доступностью `always` будет восстановлен
изначальный признак изучения. Изменённые вручную ингредиенты,
названия, категории и результаты сохраняются. Отдельное действие
доступно в истории отмены.

Важно: импорт по-прежнему создаёт отдельный рецепт редактора и
**не удаляет автоматически** оригинальную запись из игровых скриптов.
При необходимости заменить именно ванильный способ приготовления
следует отдельно реализовать замещение штатного `C_Info`.
