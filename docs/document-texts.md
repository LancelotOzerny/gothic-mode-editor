# Тексты книг и записок Gothic

Для проекта создайте UTF-8 файл, например:

`Assets/Texts/Recepts/Potions/recept-potions-exp-100.md`

```md
# Зелье опыта

Для приготовления понадобятся:
трава, вода и пустая колба.

Измельчите траву и варите смесь на алхимическом столе.

# Примечание алхимика

Без предварительного обучения приготовить зелье не удастся.
```

Откройте в редакторе предмет категории **Документы и книги**
(книгу или записку), в секции **Чтение** выберите
**Текст книги / записки** → `recept-potions-exp-100.md`.

Поддерживаются файлы `.md` и `.txt` в любой вложенной папке `Assets/Texts/` (например, `Recepts/Potions/`, `Books/`, `Notes/`), кодировка UTF-8:
- `# Заголовок` — заголовок с отдельным шрифтом.
- Пустая строка — новый абзац.
- Обычный текст — переносится по словам; количество видимых страниц (1 или 2)
  определяется автоматически.

В движке Gothic 2 обычная книга показывает не более двух физических страниц
за одно открытие, поэтому при переполнении текстом сборка прерывается с ошибкой.
Расширенные книги с перелистыванием более двух страниц — отдельная задача.

Редактор при сборке создаёт функции `Doc_Create`, `Doc_SetPages`,
`Doc_PrintLines`, `Doc_Show` в staging; оригинальные файлы Gothic
не изменяются. Исходный MD-файл не упаковывается в MOD.

**Действия:** у документа можно оставить выбранные в редакторе действия,
например «Изучить рецепт» — они исполнятся при чтении. Если у исходной
книги уже был обработчик чтения, его старое отображение заменяется
сгенерированным текстом, чтобы на экране не открывались две книги.
Если в старом обработчике были особые побочные эффекты, перенесите их
в обычные действия документа.

Для новой книги файл можно создать вручную в папке проекта. При отсутствии
файла сборка сообщит об ошибке, не пропуская текст молча.
